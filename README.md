# 世界观定制协议

> 一套用于让 AI 稳定、可控地生成「有世界观的原创角色」的提示词工程规范。
> 把"世界观 → 居民 → 角色"的链路标准化，避免每次让 AI 自由发挥时角色性格漂移、世界观崩坏。

---

## 这是什么

如果你用过 ChatGPT / Claude / DeepSeek 等大模型做角色设定或小说创作辅助，大概率遇到过：

- **角色性格漂移**：同一个角色在多轮对话里性格前后不一致
- **世界观崩坏**：AI 自由发挥时把现代科技塞进中世纪奇幻世界
- **角色关系混乱**：A 是 B 的师父，下一轮 AI 又说他们是兄弟
- **设定无法复用**：换一次对话就要重新介绍一遍世界观
- **AI 输出格式随机**：每次给的设定卡字段都不一样，无法结构化存储

这套协议就是为了解决以上问题。它定义了：

1. **世界圣经**：世界观的"宪法"，AI 必须严格遵守
2. **居民资料卡**：世界中可出现角色的总目录
3. **角色核心描述（roleCore）**：单个角色的稳定内核
4. **角色形象设定图（Character Sheet）**：用于图像生成的视觉规范
5. **AI 执行指令模板**：让 AI 按规范输出的指令格式

## 快速开始

### 1. 读总则和流程

先读 [00.项目编写规范.md](./00.项目编写规范.md) 和 [01.世界观定制流程.md](./01.世界观定制流程.md)，理解整体工作流。

### 2. 创建你的世界

按 [02.世界圣经规范.md](./02.世界圣经规范.md) 的模板，让 AI 帮你生成一个世界圣经：

```
请按 99.AI执行指令模板.md 中的"世界圣经生成指令"，
为我生成一个【你的世界观主题，如：赛博朋克+东方仙侠】的世界圣经。
```

### 3. 生成居民目录

基于世界圣经，生成居民资料卡：

```
请按 99.AI执行指令模板.md 中的"居民目录生成指令"，
基于我的世界圣经，生成 10 个居民资料卡。
```

### 4. 深化单个角色

挑一个感兴趣的居民，深化为完整角色：

```
请按 99.AI执行指令模板.md 中的"角色核心描述生成指令"，
把居民【角色名】深化为完整的 roleCore。
```

### 5. 生成视觉设定图

最后生成角色的视觉设定：

```
请按 99.AI执行指令模板.md 中的"Character Sheet 生成指令"，
为角色【角色名】生成图像生成 prompt。
```

把生成的 prompt 喂给 Stable Diffusion / Midjourney / 其他图像生成模型即可。

## 核心设计理念

### 1. 分层而非合并

很多 AI 角色生成工具试图用一个超长 prompt 搞定一切。本协议反其道而行之，把设定**分层**：

- **世界层**：世界圣经（不常改）
- **目录层**：居民资料卡（偶尔加新角色）
- **内核层**：roleCore（角色定稿后冻结）
- **视觉层**：Character Sheet（可多版本）

每层独立维护，AI 生成时只读需要的层，避免 token 浪费和上下文污染。

### 2. 字段冻结机制

roleCore 一旦定稿，关键字段（性格、核心动机、关键关系）**冻结**，不允许 AI 在后续生成中修改。
这保证了角色的稳定性。

### 3. 指令模板化

[99.AI执行指令模板.md](./99.AI执行指令模板.md) 提供了复制即可用的指令模板，无需手写复杂 prompt。
每个指令都明确指定了：

- 输入：需要 AI 读哪些协议文件
- 输出：必须包含哪些字段、什么格式
- 约束：不允许发挥的部分

### 4. 与图像生成模型解耦

Character Sheet 规范输出的是**模型无关的 prompt 模板**，可适配 Stable Diffusion / Midjourney / DALL-E / 国产模型（如可灵、即梦）等。

## 与 AI 导演工作台的关系

这套协议是 [AI 导演工作台](https://github.com/cckais/ai-director-workbench) 的理论基础：

- AI 导演工作台中的「世界观」字段 → 对应本协议的「世界圣经」
- AI 导演工作台中的「智能体」字段 → 对应本协议的「roleCore」
- AI 导演工作台中的「起首语」字段 → 对应本协议的「AI 执行指令」前置上下文

你可以：

1. 用本协议离线设计角色（纯文本，无成本）
2. 把定稿的设定导入 AI 导演工作台
3. 在工作台中批量生成角色对话和图像

## 适用场景

- **小说创作**：维持长篇小说中角色性格一致性
- **游戏开发**：NPC 角色设定标准化
- **AI 角色扮演**：让 AI 扮演的角色有稳定的性格和背景
- **漫画/动画前期设定**：世界观和角色设定的结构化文档
- **TRPG 跑团**：GM 快速构建世界观和 NPC
